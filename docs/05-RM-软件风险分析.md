## 2. 软件安全性级别论证（62304 §4.3）

- 伤害来源：机械振动/温升作用于人体（非生命支持、非植入、有人值守）。
- 最坏可信场景：主机失效+故障漏报叠加 → 持续过量振动 → 软组织不适/轻度损伤，**不可能致命**。
- 现有控制（硬件急停 T2、板载自保护故障闭锁、软件三层兜底）已将风险降至可接受。
- **结论：建议 B 级**；注册方确认后如判 C 级，触发 D26 升级路径（详设单元级细化+覆盖率分析），
  本文档危险源表与控制措施不变，仅验证深度增加。（→ 待办 T6）
