## 2. 通讯协议层（SRS-010…）

| ID | 需求 | 来源 | 验证 |
|---|---|---|---|
| SRS-010 | 帧格式：固定 8 字节 [帧头, 0x08, 地址, D3, D4, D5, CRC_lo, CRC_hi]；CRC 为 CRC16/MODBUS（多项式 0xA001 反射，初值 0xFFFF），**低字节在前** | URD-008, 协议§2 | T |
| SRS-011 | 帧编码应对越界输入防御性拒绝（地址/数据超 8 位等返回无效），不得产生畸形帧上总线 | D11 防御性设计 | T |
| SRS-012 | 应答帧头映射：0x11=Ack、0x12=转速、0x13=位置、0x14=故障/温度/状态；应答地址须与请求地址严格匹配，不匹配丢弃 | 协议指令表, D5 | T |
| SRS-013 | 字节流同步器应从任意噪声流中滑窗定位合法帧（帧头白名单+长度+CRC 校验），坏帧静默丢弃不中断后续同步 | 协议§2, D11 | T |
| SRS-014 | 总线为半双工严格一问一答：任一时刻至多一个未完成事务；控制帧（0x55/0xAA/0x54）可插队优先于轮询 | D5 | T |
| SRS-015 | 无应答重试：等待 ≥2ms 重发，最多 3 次；重试耗尽判事务失败 | 协议§2, D5 | T |
| SRS-016 | 连续 5 个轮询周期无应答 → 该地址判离线（Absent）；恢复应答 → 重新在位 | D5, URD-008 | T |
| SRS-017 | 轮询预算：在位/状态（0x58）每头每 500ms；运行中转速（0x56）每头每 1s；6 头全轮询周期 <100ms @57600bps | D5 | T |
| SRS-018 | 上电/软件启动应对全部绑定地址逐个发滑行停止帧（0x55 速度0），防主机崩溃后电机残转；该动作写入审计（STOP_ALL_ON_BOOT） | URD-014, D5/D19 | T |
| SRS-019 | 0x60 广播指令不得使用；0xAA 仅允许维护模式单头流程使用 | 协议警告, D2 | T |
| SRS-020 | 串行传输层应经 ITransport 抽象接入（QSerialPort 实现 / Mock 注入）；串口错误（拔线等）上报并写入审计（SERIAL_ERROR） | D11, D24★ | I（M3.6 socat 实串口闭环记录见 VR；Mock 注入路径由全部集成测试覆盖） |
| SRS-021 | 频率→帧编码：RPM=Hz×60；闭环字节=0x1000\|RPM 高字节在前；50Hz→3000RPM≤协议上限 3001 | URD-002, D1 | T |
| SRS-022 | 缓启动参数应在初始化写入 0x54（限流 0x4D、缓启动 0x10、换向延时 0x00），保证暂停后柔和恢复 | D3, §2 冻结帧表 | T |
