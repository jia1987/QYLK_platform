> 对应 IEC 62304 §5.1（软件开发计划）。本计划覆盖软件生存周期全过程；
> 项目特点：**无现成质量体系**，文档链随开发产出（D12），注册路径待 T6 确认。

## 1. 目的与范围

开发台式按摩仪多设备控制软件（6 治疗头 RS485 上位机），用于三维螺旋振动治疗，
目标 NMPA 二类（暂定，T6）注册。范围：上位机软件全生存周期（需求→设计→实现→验证→
发布→维护）；**不含**：电机驱动板固件（外购 SOUP，见 MDS-SOUP-008 S7）、整机电气、
临床评价。

## 2. 生存周期模型

**里程碑迭代 + V 模型映射**（每里程碑内完成一段 V）：

```
URD(01) ──────────────────────────────── 系统验证（RK 实机 T3 + 临床确认）
  └ SRS(02) ────────────────────────── 集成/验收测试（audit_flow、maint_burn、socat 闭环）
      └ SAD(03)/SDD(04) ──────────── 集成测试（Qt 侧）
          └ 实现（src/） ──────── 单元测试（core/audit 纯 C++，双平台）
风险管理（RM 05）贯穿全程：每个里程碑过 HAZ 表复审；追溯矩阵（TRM 06）脚本门禁零缺口
```

## 4. 角色与职责

| 角色 | 承担 | 职责 |
|---|---|---|
| 产品/临床/法规接口 | 用户（jiapengpeng，硬件与医疗器械背景） | 需求确认（grill-me 拷问应答）、临床参数终审接口（T5）、注册方/硬件方待办跟催（T2/T3/T6/T7/T9/T10）、**所有提交与发布的批准人** |
| 软件开发 | AI 辅助开发（Claude Code）+ 用户评审 | 设计文档产出、实现、测试、缺陷修复（ISS 流程）；**每 commit 经用户指令批准** |
| 验证 | 自动化（ctest 双平台）+ 用户抽查 | 单元/集成测试全绿为提交门禁；系统级实机验证（M5）由用户执行、记录归档 VR |

> 说明（如实呈现）：本项目无独立测试团队与质量部；62304 要求的「职责分离」通过
> 「开发产出 → 用户批准提交 → 自动化测试门禁 → 文档签署页手签」组合实现。
> 注册申报时如检验所/审评对角色分离有进一步要求，随 T6 补充组织性证据。

## 5. 交付物清单（每里程碑）

代码（src/tests/tools）+ 文档增量（docs/ 对应章节）+ 测试记录（ctest 输出归档 VR）
+ 追溯矩阵重生成（gen_trm.py）+ ISSUES 更新 + commit（用户批准）。

## 6. 评审与门禁

| 门禁 | 时机 | 通过准则 |
|---|---|---|
| 需求拷问（grill-me） | 每里程碑动工前 | 决策全部锁定入设计方案，无开放硬矛盾（或已登记 T/ISS） |
| 构建门禁 | 每次提交前 | 双平台（Win MinGW/Qt6.9 + WSL Ubuntu20.04/Qt5.12.8）构建零错误零警告 |
| 测试门禁 | 每次提交前 | ctest 全量全绿；新增行为必须有测试（安全关键路径必须集成测试） |
| 追溯门禁 | 每次提交前 | `gen_trm.py --check` 零缺口（DoD#4） |
| 提交批准 | 每次提交 | 用户明确指令（「提交 Mxx」） |
| 发布冻结 | 1.0.0 | MDS-VC-010 §4 清单逐项核对 + 签署页手签 |

## 7. 风险管理活动（引用 MDS-RM-005）

- 每里程碑：HAZ 表复审（新功能/变更是否引入危险源）；
- ISS（严重度≥重要）：强制触发 HAZ 复审；
- 生产信息（部署后现场反馈）：入 ISSUES → 复审 → 必要时变更控制；
- 开放风险项跟踪：T2（急停）、ISS-012（方向确认）、ISS-013（预设门禁）。

## 8. 配置与文档管理（引用 MDS-VC-010）

git 单主干 + 语义化 tag；文档中文 md 入仓、签署页手签归档、发布时 pandoc 转 PDF；
文档编号体系见 MDS-IDX-000。

## 9. SOUP 管理（引用 MDS-SOUP-008）

新增先入清单；升级走变更控制；发布冻结前复查安全通告。

## 10. 维护与问题解决（引用 MDS-ISS-009）

发布后缺陷：ISS 登记 → 严重度评估 → 修复（含回归测试）→ HAZ 复审（≥重要）→
修订版本发布（0.3.x/…）。维护记录与生产信息反馈闭环保留至产品停售后按法规年限。

## 11. 开发环境与安全

- Windows 11 开发机（subst M: 规避中文路径）+ WSL2 Ubuntu-20.04（目标同版验证）；
- 构建：CMake+Ninja（Win MinGW 13.1 / WSL gcc 9.4）；工具链版本记录于 MDS-SOUP-008 §2；
- 仓库备份：远端 origin（推送策略由用户掌握）；发布 tag 后建议离线归档一份冻结源码包。
