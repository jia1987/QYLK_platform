## 1. 产品定位

康复科/理疗科台式设备：治疗师通过触摸屏独立控制 **6 个治疗头**（左 L1–L3 / 右 R1–R3，
局部/手法/靠垫三种类型）的三维螺旋振动治疗。设备为**非生命支持、有人值守**场景，
治疗师全程在场；硬件急停为最终兜底（T2 书面确认中）。

## 2. 用户需求

| ID | 需求 | 说明/验收视角 |
|---|---|---|
| URD-001 | 独立控制 6 个治疗头 | 每头可独立启停/调参，互不影响；界面按 L/R 侧 6 卡片布局 |
| URD-002 | 振动频率 10–50Hz 可调 | 步进 5Hz；上限受电机协议闭环 3001RPM 物理约束（原型 100Hz 为错误，已修正） |
| URD-003 | 三种治疗模式 | 恒频 / 扫频（周期往复）/ 阶频（梯形爬升-保持-下降），曲线参数临床终审中（T5） |
| URD-004 | 治疗时长 5–60min 倒计时 | 到时自动柔和停止；剩余时间与进度可视 |
| URD-005 | 6 个一键预设 | 常用「频率×模式×时长」组合；治疗师可将当前参数存为预设 |
| URD-006 | 暂停/继续为柔和语义 | 暂停=滑行停止+倒计时冻结；继续=缓启动柔和爬升，无机械冲击 |
| URD-007 | 故障可见可复位 | 板载故障（过压/欠压/过温/霍尔/堵转/短路）卡片红色显示故障名；治疗师排查后手动复位才能重启 |
| URD-008 | 治疗头在位可视 | 无 ID 协议 → 在位检测（轮询应答）；未插/拔出实时反映在卡片 |
| URD-009 | 运行中失联强告警 | 治疗中总线断（拔线等）→ 醒目告警提示电机可能仍在转、指引硬件急停 |
| URD-010 | 换头/绑定维护流程 | PIN 保护的维护模式：槽位↔地址↔类型绑定、新头单头烧录地址（严禁总线广播）、方向试运行确认 |
| URD-011 | 设置门禁 | 系统设置/绑定维护/预设修改/日志导出需 PIN（4–6 位）；主治疗界面不设限（临床效率） |
| URD-012 | 治疗记录可追溯（注册必需） | 谁、何时、对哪个头、用什么参数、结果如何——完整审计；故障与复位、设置与绑定变更、PIN 操作全部留痕；记录只增不删 |
| URD-013 | 记录可导出可查验 | PIN 保护下导出到 U 盘（医院设备科/注册检验取数）；应用内可分页查询近期记录 |
| URD-014 | 断电/崩溃不失控不丢账 | 主机异常重启后电机不得残转（上电全停清理）；审计记录不因断电丢失；异常重启自身留痕 |
| URD-015 | 时间可校准且记录不受改钟污染 | 应用内设系统时间；审计时序以单调时钟锚定，改钟可被发现和解释 |
| URD-016 | Kiosk 部署 | RK3568 触摸屏一体机全屏运行、开机自启、崩溃自动重启；1920×1080 基准，兼容 1280×800（T3 屏幕冻结后终调） |
| URD-017 | 满足 NMPA 注册文档要求 | IEC 62304 文档链随开发产出；软件版本命名规则明确；SOUP 清单及评估完整 |

## 3. 约束与假设

| 类别 | 内容 |
|---|---|
| 协议约束 | 帧长固定 8 字节；CRC16/MODBUS lo-first；半双工一问一答；0xAA 严禁广播；异常重发间隔 ≥2ms |
| 硬件假设 | 单头独立 24V 供电（DC 8–26V）；极对数 2；硬件急停存在（T2 待书面确认）；USB-RS485 转换器驱动在树（T7） |
| 平台假设 | Ubuntu 20.04 自带 Qt 5.12.8；eMMC 数据区可用 ≥2GB（T9）；RTC 电池状态待确认（T9） |
| 使用假设 | 科室共用设备、多名治疗师轮班（操作员名单制，非个人密码账户）；设备不联网（无 NTP/远程维护，T6 网络安全级别确认后复核） |
| 法规假设 | 软件安全性级别暂定 B（T6 注册方确认后如需 C 级，按 D26 缓冲路径升级文档） |
