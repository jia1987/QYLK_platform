## 1. 产品概述

控制 **6 个治疗头**（L1–L3 / R1–R3 逻辑槽位）的三维螺旋振动治疗系统上位机软件。
治疗头内置无刷电机驱动板，挂 **单条 RS485 总线**，主机轮询控制。

- 界面原型：`技术方案/台式设备交互界面-单文件离线版.html`
- 通讯协议：`技术资料/北京枢点RS485通讯协议.pdf`（14 页）
- 目标平台：**RK3568/RK3566 (arm64) + 触摸屏，Ubuntu 20.04**
- 语言/框架：**C++ / Qt5 QML（Ubuntu 20.04 自带 Qt 5.12.8）+ QSerialPort**
- 合规目标：**NMPA 医疗器械注册**（无现成质量体系，文档随开发产出）

## 2. 协议层事实（已核实）

| 项目 | 值 | 来源 |
|---|---|---|
| 串口参数 | **57600, 8N1** | PDF p2 |
| CRC | **CRC16/MODBUS，低字节在前** | 用附件例帧 `AA 08 01 00 14 02 76 ED`、`55 08 01 0B B9 01 2F B1` 实算验证通过 |
| 帧长 | 固定 8 字节 | PDF |
| 异常重发 | 等待 ≥2ms 后重发 | PDF p2 |

### 指令表（本软件用到的）

| 帧头 | 方向 | 用途 | 备注 |
|---|---|---|---|
| `0xAA` | 主→机 | 配置地址/开闭环/堵转时间/极对数 | **严禁上总线广播**（会改写所有设备地址）；仅维护模式单头烧录用；带记忆 |
| `0x54` | 主→机 | 限流/缓启动/正反转延时 | 带记忆；缓启动建议 ≤0x10 |
| `0x5D` | 主→机 | 霍尔相序矫正 | 出厂/维修用，应答含正确霍尔状态值 |
| `0x55` | 主→机 | **核心控制**：占空比或转速 + 状态字 | 状态字：00 A转 / 01 B转 / 02 复位+A / 03 复位+B / 04 刹车；闭环=数值最高位置1（`0x1000\|RPM`），最低 100RPM，上限 3001 |
| `0x56/57/58` | 主→机 | 读转速 / 位置 / 故障码+温度+运行态 | 应答 `0x12/0x13/0x14` |
| `0x60` | 主→机 | 广播全电机 | 无应答，文档不建议常规使用；本软件**不用**（改逐个发 0x55） |

不使用：`0x59`（定零位）、`0x5A`（位置控制）——三种治疗头统一速度控制，无位置模式。

### 故障码（0x58 应答第4字节，位掩码）
`0x01` 过压 `0x02` 欠压 `0x04` 过温 `0x10` 霍尔异常 `0x20` 堵转 `0x40` 短路；`0x00` 正常，`0x80` 电机运行中。

### 冻结帧表（地址=01 示例，CRC16/MODBUS 已实算；其他地址替换第 3 字节后重算 CRC）

| 用途 | 完整帧 |
|---|---|
| 出厂初始化：地址1+闭环+堵转2s+极对数2 | `AA 08 01 10 14 02 77 28` |
| 参数配置：限流0x4D(≈10A)+缓启动0x10+换向延时0 | `54 08 01 4D 10 00 70 25` |
| 运行：闭环 1800RPM(30Hz) A向 | `55 08 01 17 08 00 5B E7` |
| 运行：闭环 1800RPM(30Hz) B向 | `55 08 01 17 08 01 9A 27` |
| 滑行停止（速度0） | `55 08 01 00 00 00 EC 23` |
| 故障复位+A向 | `55 08 01 00 00 02 6D E2` |
| 故障复位+B向 | `55 08 01 00 00 03 AC 22` |
| 刹车（预留能力） | `55 08 01 00 00 04 ED E0` |
| 读转速 | `56 08 01 33 33 33 48 FA` |
| 读故障/温度/状态 | `58 08 01 33 33 33 49 D4` |

频率→帧编码：`RPM = Hz×60`，闭环字节 = `(0x1000 | RPM)` 高字节在前。
例：10Hz→`12 58`，30Hz→`17 08`，50Hz→`1B B8`（≤ 上限 `1B B9`=3001）。

**注**：缓启动取 0x10（文档「常规应用建议不超过 0x10」的上限）——出厂寄存器默认 0x01 启动太硬，不满足 D3「暂停后柔和恢复」，软件初始化时写入 0x10。若堵转频发可按文档提示同步增大堵转时间。

## 3. 已锁定决策（五轮拷问结论）

### D1 频率映射与量程
- **RPM = Hz × 60**，振动频率 = 电机转频，无机械增速。
- 协议闭环上限 3001RPM → **UI 量程修正为 10–50Hz，步进 5**（原型的 10–100Hz 是错误）。
- 预设6 由 `100Hz·恒频·5min` 改为 **`50Hz·恒频·5min`**；其余 5 个预设不变（15/30/40/50/60Hz 中 60Hz 超限 → 预设4 `50Hz·恒频·15min` 与预设5 `60Hz→50Hz·扫频·10min` 需按新上限归整，最终预设表见 D10）。
- 电机极对数 = **2** ✅ 已由电机规格书背书（FG 反馈：两对极磁环电机转一圈输出 2 个方波脉冲，转速=FG×60/极对数）。
- 电机工作电源：**DC 8–26V，单头独立 24V 供电**（已确认；协议侧过压保护 34V）。欠压(0x02)/过压(0x01)故障码与此相关——单头独立供电下无共母线互扰压降，主电源总容量按 6 头最坏并联电流设计（限流封顶 ≈10A/头）。
- 控制方式：**闭环转速**（`0x1000|RPM`，50Hz=3000RPM≤协议上限3001，**3000RPM 长时间运行已获硬件方确认 ✅**）。闭环下限 100RPM≈1.7Hz，不构成约束。
- 规格书的 IO 控制通道（PWM/F-R/BRA 引脚，注意其 PWM 为反逻辑：<0.5V 全速、>4.5V 停止）**不使用**，本软件仅走 485；硬件刹车 BRA 对应 485 状态字 04，作为预留能力（当前暂停/停止均滑行停止，见 D3）。

### D2 治疗头识别与绑定
- 协议无 ID 指令 → **仅做在位检测**（轮询 0x58 有应答=在位）。
- 驱动板在治疗头内，出厂烧好地址（1–6）；**软件配置文件维护「485地址 → 槽位(L1..R3) → 类型(局部/手法/靠垫)」映射**。
- 软件内置**维护/绑定模式**（PIN 保护）：
  - 扫描总线发现在位头；
  - 绑定/解绑槽位与类型；
  - **换头烧地址流程**：提示只连接一个新头（或断开总线单接）→ 检测地址 0 设备 → `0xAA` 烧新地址（极对数=2、堵转 2s、闭环模式）→ 引导绑定槽位与类型 → **设定运行方向（A/B 转向）并低速试运行确认**。

### D3 控制语义（状态机）
- 每个头独立状态机：`Absent → Idle → Starting(缓启动) → Running → Paused → Stopping → Fault`。
- **暂停** = 发 `0x55` 速度 0（<50 即 0 速）→ **电机惯性滑行停止**，倒计时冻结。
- **继续** = 重发目标转速，依赖板载缓启动自然爬升（`0x54` 缓启动值 ≤0x10）。
- **停止/倒计时归零** = 同滑行停止语义，计时归零，回 Idle。
- **故障**（0x58 报非零故障码）：该头卡片变红显示故障名，软件停发运行指令（板子已自保护），治疗师排查后在 UI 点「复位」→ 发 `02/03` 复位帧 → 成功回 Idle 才能重新启动。
- 运行中允许实时改频率/模式/时间（原型行为），改动经 ProfileEngine 平滑下发。

### D4 曲线引擎（扫频/阶频参数已定，写死为代码常量表）
- 恒频：目标 RPM 恒定。
- **扫频**：三角波 0 → 设定频率 → 0，**周期 10s**。
- **阶频**：梯形波，**周期 20s**：爬升 4.8s → 保持 5.2s → 下降 4.8s → 低保持 5.2s；**低保持段频率 = max(10Hz, 设定频率×50%)**。
- 主机 **250ms** tick 计算瞬时目标转速，变化超过阈值（±30RPM）才入队 `0x55` 下发，避免总线拥塞。
- 所有曲线参数集中一个常量结构体，改数值不动架构（临床数值终审 → 待办 T5）。

### D5 总线调度
- 单线程异步 QSerialPort + 请求队列，**半双工严格一问一答**。
- 每头轮询预算：在位/状态 0x58 每 500ms；运行中转速 0x56 每 1s；控制帧 0x55 事件触发插队（高优先级）。
- 57600bps 下 8 字节帧≈1.4ms 单向，6 头全轮询周期 <100ms，余量充足。
- 超时重试：等 2ms 重发，最多 3 次；连续 5 个轮询周期无应答 → 标记 **离线（Absent）**，运行中的头离线 → UI 醒目告警（治疗头在位但总线断 = 电机可能仍在转，提示按急停）。
- 上电/软件启动清理：对地址 1–255 逐个发 `0x55` 速度 0 停止帧（约 2s），防主机崩溃重启后电机残转。

### D6 安全兜底
- **硬件急停断电为最终兜底**（用户称硬件有，待书面确认 → 待办 T2）。
- 软件侧：systemd 看门狗 + 应用崩溃自动重启（重启即触发 D5 上电清理）；治疗倒计时、故障监控全在主机。
- 风险分析文档中此路径（主机死机→电机失控）必须记录并引用硬件急停作为风险控制措施。

### D7 GUI 技术
- **Qt5 QML**（Qt 5.12.8），暗色主题 1:1 还原原型：左右侧卡片、中央参数区、底部操作栏、Modal、Toast、设置面板。
- 基准分辨率 **1920×1080**，布局自适应兼容 1280×800（RK 屏最终确认后调整 → 待办 T3）。
- 波形图为 QML Canvas/Shape 静态示意图（按模式绘制，同原型，非实时曲线）。
- 触摸屏：按钮尺寸沿用原型（≥44px 触控目标），长按连发（▲▼ 按钮 450ms 后 110ms 重复）保留。
- 频率控件量程改 10–50Hz（D1），预设区文案同步修正。

### D8 平台接入
- 串口：**USB-RS485 转换器**，udev 规则固定别名（按转换器 VID/PID 或序列号 → `/dev/massage485`），串口路径/波特率做成配置项。
- 转换器芯片选型需确认 Ubuntu 20.04 内核驱动在树（CH340/FT232/CP210x 均支持 → 待办 T7）。
- Kiosk：全屏运行、自动登录、systemd 服务自启、禁用桌面手势。
- 系统时间设置：应用内调用 `timedatectl`（polkit 授权运行用户）；治疗审计时间戳用单调时钟+RTC 双记，防止改时间污染记录。

### D9 访问控制与审计（注册要求）
- **设置面板 PIN 门禁**（4–6 位，默认 PIN 首次启动强制修改；PIN 加盐哈希存储）。主治疗界面不设限。
- PIN 保护范围：系统设置、绑定/维护模式、预设修改、日志导出。
- **审计追踪（SQLite）**：
  - 治疗记录：开始/暂停/继续/停止/完成事件，槽位、地址、频率、模式、时长、实际运行秒数；
  - 故障与复位事件（故障码、温度、时刻、复位结果）；
  - 设置变更（旧值→新值）、绑定变更、PIN 修改；
  - 记录只增不删，导出功能（PIN 保护）。

### D10 预设与持久化
- 6 个预设位（点一次应用、30s 内再点一次存为预设——原型交互保留），持久化到配置。
- 修正后默认预设表：
  1. 15Hz·恒频·20min　2. 30Hz·扫频·30min　3. 40Hz·阶频·20min
  4. 50Hz·恒频·15min　5. 50Hz·扫频·10min　6. 50Hz·恒频·5min
- 配置持久化：JSON（`~/.config/…` 或 `/etc/…`，随部署定），内容：串口路径、地址↔槽位↔类型映射、**每头运行方向（A/B 转向）**——规格书明言 F/R 电平与正反转对应关系「由实际电机决定」，485 侧 A/B 转向又取决于霍尔相序与三相线序，故方向必须逐头可配置并在绑定/换头时试运行验证、预设、医院/科室、PIN 哈希、曲线常量覆盖（预留）。

## 6. 拷问中暴露并已消灭的原型/协议缺陷

1. UI 频率 10–100Hz 超出协议能力（3001RPM≈50Hz 封顶）→ 量程修正 10–50Hz。
2. 「插上自动识别类型」协议不支持 → 改为在位检测+绑定配置。
3. 无暂停指令 → 定义为滑行停止+缓启动恢复。
4. 原型无故障态 UI → 新增卡片故障态+手动复位流程。
5. 主机崩溃=电机失控（协议无看门狗）→ 硬件急停兜底+启动全停清理+看门狗进程。
6. 新头默认地址 0 上总线必冲突 → 维护模式单头烧地址流程。
7. 设置面板零门禁 → PIN。
8. 无治疗记录 → SQLite 审计追踪（注册必需）。
9. CRC 算法文档未指明 → 实算确认为 CRC16/MODBUS lo-first。
10. 广播指令 0x60 无应答不可靠 → 弃用，逐地址控制。
